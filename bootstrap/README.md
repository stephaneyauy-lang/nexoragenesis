# Seed minimal

`seed/seed0-bytes.md` décrit les octets du seed initial ; `seed/seed0.sha256` en donne l'empreinte de référence. Cette édition n'embarque pas les images de disque de test.

Les anciens bootstrap S0, NASM et leurs campagnes sont dans `../legacy/`. Le bootstrap C encore actif est classé avec le compilateur, dans `../compiler/c/`, et n'est pas présenté comme une dépendance supprimée.
