# Anciennes versions et outils archivés

**Hors du build normal actuel.** Ces fichiers sont conservés pour expliquer l'historique et permettre des comparaisons ciblées. Les chemins, scripts et preuves de ces anciennes campagnes peuvent nécessiter leur environnement d'origine ; leur archivage n'est pas une nouvelle validation.

| Dossier | Ancien rôle |
|---|---|
| `ntasm-v0/` | Voie native NTASM antérieure, distincte de la chaîne Nova actuelle |
| `nova-bootstrap/` | Première verticale du compilateur Nova |
| `native-build/` | Lanceur natif S0 historique |
| `ntasm-s0/` | Sources et corpus des étapes S0 |
| `nasm/` | Producteur NASM historique, interdit dans le build normal |
| `bootstrap-seeds/` | Étapes et descriptions de seeds antérieurs |
| `tools/`, `scripts/` | Instruments et campagnes historiques |
| `docs/` | Documentation historique, pas le guide courant |

Les OS sont dans `../examples/os/`, pas ici. Le bootstrap C encore utilisé reste dans `../compiler/c/`.
